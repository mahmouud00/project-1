# SUITES — نظام إدارة مصانع البدل (MYTECH Solutions)

برنامج ديسكتوب (ويندوز) **من غير إنترنت**: قاعدة البيانات على جهاز واحد فى المحل (السيرفر)،
وباقى الأجهزة بتتصل بيه على شبكة المحل. بيتباع بترخيص لكل شركة: **شهر / 6 شهور / سنة / مدى الحياة**،
وعدد المستخدمين جزء من الترخيص. لما الترخيص يخلص البرنامج بيفضل **للعرض بس**.

مبنى بنفس طريقة «البرنامج العام» (PySide6، نفس الصفحات والصلاحيات والشكل)، بس:
- Supabase اتشال ← سيرفر محلى جوه البرنامج نفسه (SQLite)، ومفيش إيميلات: الدخول باسم مستخدم وباسورد.
- الصفحات بقت لمصنع بدل: عملاء ومقاسات، طلبات تفصيل، قص/خياطة/بروفة/تشطيب، تسليم، مخزن خامات وبدل جاهزة، عمال وأجور.
- ملاحظات ملف الـ Word اتعملت كلها: الكلام فى الخانات واضح، فاتح/داكن/زى الجهاز، إيقاف وحذف موظف،
  لوجو واسم الشركة فوق على الشمال مكان «جارى التحميل».

## دورة الطلب

```
طلب جديد (المقاسات + الموديل + العربون)
   ← ✅ تأكيد العربون (الحسابات) ← العربون يدخل الخزينة
   ← ✂️ القص (مين قص + الخامات اللى اتصرفت تتخصم من المخزن)
   ← 🧵 الخياطة ← 🪞 البروفة (لو محتاجة تعديل ترجع للخياطة) ← ♨️ التشطيب
   ← 📦 التسليم للعميل (المحصّل + طريقة الدفع)
   ← ✅ تأكيد الحساب النهائى (الحسابات) ← الفلوس تدخل الخزينة ← 📜 المبيعات
```
- **العمال:** كل عامل بالقطعة أو مرتب أو الاتنين (الشركة بتحدد). اللى بالقطعة أجره بيتسجل أوتوماتيك
  لما يخلّص مرحلة، حسب «أسعار القطعة» فى الإعدادات. كشف أجور شهرى + سلف + مكافآت + خصومات.
- **معادلات الخامات (تركيبة كل نوع):** فى الإعدادات ← «🧮 تركيبة الخامات». لكل نوع شغل الخامات وكميتها للقطعة،
  رقم ثابت أو معادلة بالمقاسات، مثال: `تقريب(([جاكيت الطول] + [جاكيت طول الكم]) ÷ 100 + 0.35، 0.25)`.
  الطلب بيحسبها لوحده ويحجزها من المخزن (القماش اللى اتختار من المخزن + البطانة والزراير...)، وشاشة «تم القص»
  بتفتح والكميات مكتوبة، القصاص يعدّلها لو اللى اتصرف مختلف. تفاصيل الموديل ممكن تزوّد قماش
  (اكتب جنب الاختيار `= +0.3`). كل شركة بتعدّل المعادلات على طريقة شغلها، وفيه زرار «🧪 جرّب».
- **المخزن:** استلام خامات (متوسط السعر بيتحسب، والفاتورة بتتسجل على المورد)، صرف، جرد، تنبيه لما خامة تقرب تخلص.
- **البدل الجاهزة:** أصناف بمقاس ولون، بيع جاهز من صفحة الطلبات (الفلوس بتدخل الخزينة على طول).
- **الطباعة:** إيصال للعميل، ورقة شغل للمصنع (المقاسات من غير أسعار)، فاتورة البيع الجاهز. (تقدر تحفظها PDF من «Microsoft Print to PDF»)

## أول مرة على جهازك (إنت كمطوّر/بائع)

افتح **CMD** (مش PowerShell) فى فولدر `final_system`:
```
py -3.13 -m venv .venv313
.venv313\Scripts\activate.bat
python -m pip install -r app\requirements.txt
```

### 1) اعمل مفتاح التراخيص (مرة واحدة بس فى العمر)
```
python license_tool\keygen.py
```
- بيعمل `license_tool\seller_private_key.pem` ← **ده أهم ملف عندك**: اعمله نسخة على فلاشة + Google Drive.
  لو ضاع مش هتقدر تجدد للعملاء القدام. لو اتسرق أى حد يقدر يعمل تراخيص. (الـ .gitignore مانعه يترفع على GitHub)
- وبيكتب المفتاح العام جوه البرنامج (`app\server\license_key.py`) أوتوماتيك.

### 2) شغّل البرنامج
```
python app\main.py
```
- أول تشغيل: اختار **«الجهاز ده هو السيرفر»**.
- هيطلعلك **كود الجهاز** ← افتح أداة التراخيص واعمل له كود (تحت) ← الصقه ← **تفعيل**.
- اكتب بيانات الشركة وحساب المدير ← انت جوه.

### 3) أداة التراخيص (عندك إنت بس)
```
python license_tool\license_tool.py
```
اكتب اسم العميل + **كود الجهاز** اللى بعته ← اختار الباقة وعدد المستخدمين ← **اعمل كود التفعيل** ←
«انسخ رسالة واتساب جاهزة» وابعتها. كل ترخيص بيتسجل فى `license_tool\licenses_log.csv`.
- الكود دايمًا بيبدأ **من النهارده**، وقبل ما يتعمل بيظهرلك «من كذا لحد كذا» تأكده.
- لو الجهاز اتعمله ترخيص قبل كده، الأداة بتقولك آخر باقة وإمتى بتخلص. لو العميل بيجدد بدرى وعايز ميخسرش الأيام الباقية،
  دوس «⏩ يبدأ بعد انتهاء الحالى» (الزرار ده مش بيظهر بعد التجربة: الشهر المدفوع بيبدأ من يوم الدفع).
- كل كود جديد بيلغى اللى قبله على نفس الجهاز، فلو غلطت فى كود اعمل واحد صح وابعته.
- باقة «تجربة» بعدد أيام تحدده (افتراضى 14 يوم) لو عايز تدّى حد يجرّب.

### 4) اختبارات (اختيارى)
```
python -m unittest discover tests -v
```

## عمل الـ Setup للبيع

1. ثبّت **Inno Setup 6** من https://jrsoftware.org/isdl.php
2. من فولدر `app` (والـ venv متفعّل):
   ```
   cd app
   build.bat
   ```
   - بيحوّل الكود لـ exe متجمّع بـ **Nuitka** (أصعب بكتير فى فك الكود من PyInstaller). أول مرة بياخد 10–20 دقيقة
     وممكن ينزّل compiler لوحده.
   - لو Nuitka عمل مشكلة: `build_quick.bat` (PyInstaller، أسرع بس أسهل فى الفك).
3. الـ Setup بيطلع فى `app\installer_output\SUITES_Setup_1.0.0.exe`.

قبل ما تبيع:
- اسم البرنامج واللوجو: `app\app_info.py` (`APP_NAME`) + `app\installer.iss` (`MyAppName`) + `app\assets\logo.png`
  (لوجو مؤقت — حط لوجو البراند مكانه وشغّل `python make_icon.py`).
- **رقمك:** `SELLER_NAME` و `SELLER_PHONE` فى `app\app_info.py` (بيظهروا للعميل فى شاشة التفعيل والتجديد).
- متغيّرش `AppId` فى installer.iss ولا `APP_ID` فى app_info.py بعد أول بيعة.

## عند العميل

1. ثبّت الـ Setup على **كل** الأجهزة (نفس الإصدار).
2. **جهاز السيرفر** (جهاز ثابت، غالبًا جهاز المدير أو الحسابات): أول تشغيل ← «الجهاز ده هو السيرفر» ←
   ويندوز هيسأل **Allow access** ← دوس Allow (Private networks) ← ابعتلك كود الجهاز ← فعّل ← اعمل الشركة.
3. **باقى الأجهزة:** «جهاز موظف» ← «دوّر على السيرفر» (أو اكتب العنوان اللى ظاهر فى الإعدادات على السيرفر).
4. المدير من ⚙️ الإعدادات: يعمل مستخدم لكل موظف (اسم مستخدم + باسورد) ويحدد صفحاته.
   مثال: القصاص ← «القص» بس. الاستقبال ← العملاء + الطلبات + التسليم.
5. فى الإعدادات على السيرفر: علّم **«شغّل السيرفر لوحده مع ويندوز»** عشان الموظفين ميستنوش حد يفتح البرنامج.
   لو قفلت شباك البرنامج على السيرفر، السيرفر بيفضل شغّال جنب الساعة.

### التجديد
العميل ← الإعدادات ← 🔑 «إدخال كود تجديد» (أو الزرار اللى فى الشريط الأحمر/الأصفر فوق).
البرنامج بينبّه قبل الانتهاء بأسبوع. لو خلص: **للعرض بس** (يشوف كل حاجة، ويعمل نسخة احتياطية، بس مفيش إضافة ولا تعديل).

### النسخ الاحتياطى
- السيرفر بيعمل نسخة أوتوماتيك كل يوم (آخر 30 يوم) فى `%LOCALAPPDATA%\TailorMaster\data\backups`.
- الإعدادات ← «اعمل نسخة احتياطية» ← احفظها على فلاشة (مرة فى الأسبوع على الأقل).
- «استرجاع من ملف» بيرجّع البيانات (وبيحفظ نسخة من الحالية قبلها للأمان). الترخيص مش بيتأثر.

### لو جهاز السيرفر اتغيّر
انقل ملف النسخة الاحتياطية للجهاز الجديد ← ثبّت البرنامج ← «الجهاز ده هو السيرفر» ← البرنامج هيطلب تفعيل
(كود جهاز جديد) ← اعمل له كود ← اعمل الشركة بأى بيانات ← الإعدادات ← استرجاع من الملف.

## الحماية (بصراحة)
- كود التفعيل **متوقّع رقميًا (Ed25519)**: محدش يقدر يعمل كود من غير المفتاح السرى، ولا يعدّل مدة كود موجود.
- الكود مربوط ببصمة جهاز السيرفر ← مينفعش ينتقل لشركة تانية.
- رجوع تاريخ الجهاز لورا بيتكشف (البرنامج بيفتكر آخر تاريخ شافه فى مكانين) ← للعرض بس لحد ما التاريخ يتصلح.
- Nuitka بيصعّب فك الكود جدًا. بس زى أى برنامج بيشتغل من غير إنترنت: حد محترف ومصمم يقدر يكسره.
