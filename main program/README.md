## المرحلة 2: برنامج الديسكتوب

### 1) ضيف إضافات الإعدادات لقاعدة البيانات
فى Supabase ← SQL Editor ← الصق `supabase/06_settings.sql` ← Run.
هيطلّعلك جدول اختبار صغير (6 اختبارات). ابعتلى صورته.

### 2) حط بيانات الاتصال
افتح `app/app_config.py` بالنوت باد، وحط:
- `SUPABASE_URL` = الـ Project URL
- `SUPABASE_KEY` = المفتاح **publishable** أو **anon public** (مش الـ secret!)

### 3) شغّل البرنامج
افتح **CMD** (مش PowerShell):
```
cd /d "مسار فولدر app"
py -3.13 -m venv .venv313
.venv313\Scripts\activate.bat
python -m pip install -r requirements.txt
python main.py
```
المرات الجاية: `cd` ← `activate.bat` ← `python main.py` بس.

### 4) جرّب الدورة
1. **حساب جديد** بإيميلك ← **إنشاء الشركة** ← انت كده المدير.
2. ⚙️ **الإعدادات**: اتفرّج على الإعدادات الافتراضية (طرق الدفع، الأنواع، الإدارات) وعدّل اللى عايزه.
3. من **حساب تانى** (إيميل تانى) ← **انضم لشركتك** بالكود اللى فى الإعدادات.
4. ارجع بحساب المدير ← الإعدادات ← الموظف الجديد ← 🔐 الصلاحيات ← فعّله وحدد صفحاته.
5. عدّى دورة تعاقد كاملة: المبيعات ← تأكيد الحسابات ← المصانع ← التركيبات ← تأكيد الحسابات.

### 5) لما تبقى راضى: اعمل Setup
نفس خطوات وينتاج: `build.bat` (من نفس شاشة CMD والـ venv متفعّل).
الفرق: **مفيش credentials.json** - البرنامج آمن يتوزّع على أى جهاز.

| `supabase/*.sql` | قاعدة البيانات (01→06) |
| `app/main.py` | تشغيل البرنامج |
